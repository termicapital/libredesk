Libre Desk / live-data MVP

Install the live display MVP.

A private Waveshare ESP32-C6-LCD-1.3 build where you choose the 2.4 GHz Wi-Fi during installation. It uses an authenticated HTTPS bridge and contains a revocable device token and Wi-Fi password; do not redistribute it.

Install and add Wi-Fi

  1. Connect the board directly with a data-capable USB cable.
  2. Click Install and add Wi-Fi, select the ESP32-C6 serial port, and install.
  3. When installation finishes, choose Next.
  4. Enter the exact Network Name and Password for the 2.4 GHz Wi-Fi.
  5. Keep the cable connected while Libre Desk saves the network and restarts.
WebSerial is unavailable. Use desktop Chrome or Edge over HTTPS.

The Network Name and Password you enter are sent directly over the USB cable to Libre Desk. They are not uploaded to or stored by this installer server.

What should appear

The screen progresses through Wi-Fi connection, trusted-time synchronization, and live-data fetching. The larger clock is a zero-padded 24-hour HH:MM clock above a centered glucose number, with trend, range state, and reading age, without a visible unit label.

Acceptance requires two successive real readings to appear on the physical screen. Keep the display powered while the sensor publishes its next update.

Wi-Fi setup

The installer writes only the Network Name and Password. The bridge address, device token, display settings, and glucose behavior are retained automatically.

BOOT setup remains available as a fallback, but it is not part of the normal installation flow.
