# M1 contract and mock-upstream checks

The device contract is frozen at `contracts/` for M1. Changes to it must be reviewed as breaking changes across the bridge and firmware.

`tools/mock-upstream` is intentionally not an Abbott client. It is a deterministic test double for the volatile private API surface and exposes every scenario from the plan, including malformed and transport failures.

Run `make check` before committing. Install the gitleaks hook with `make install-hooks` after installing gitleaks on the VPS.
